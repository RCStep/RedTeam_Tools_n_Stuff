# Explorer_open
Usage: explorer_open.exe [create/delete] [directory]  
  
C# tool to open a local or remote folder or file with the Windows Explorer file browser.  
  
Wrap directory paths with spaces in quotes.  
  
explorer_open.exe open/select "path to folder or file"  
open: explorer window opens to the folder or the target file executed  
select: explorer window opens with folder or target file selected/highlighted
